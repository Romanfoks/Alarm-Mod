**Alarm Mod** adds functional alarm and warning light blocks to Minecraft, powered by the **Veil** rendering library. Perfect for base defense, factory hazard signaling, and technical builds.

---

## ✨ Features

* **Alarm Blocks:** Functional alarm systems with custom models and directional placement.
* **Veil Rendering:** Powered by the **Veil** engine for advanced visual rendering effects.
* **Redstone Reactive:** Toggles state instantly when powered by standard Redstone signals.
* **Visual Indicators:** Clear visual cues to display active alarms, danger zones, and power statuses.
